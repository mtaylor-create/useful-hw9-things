# MARF - Expo Project

## Expo Skills

This project uses Expo. When working on related topics, read the corresponding skill file from `.claude/skills/expo/` for up-to-date guidance:

| Topic | Skill file | When to use |
|-------|-----------|-------------|
| UI & Components | `building-native-ui/SKILL.md` | Building screens, navigation, styling, animations, native controls |
| API Routes | `expo-api-routes/SKILL.md` | Server-side API routes in Expo |
| CI/CD | `expo-cicd-workflows/SKILL.md` | Setting up build/deploy workflows |
| Deployment | `expo-deployment/SKILL.md` | Publishing to App Store, Play Store, web |
| Dev Client | `expo-dev-client/SKILL.md` | Custom development builds |
| Tailwind | `expo-tailwind-setup/SKILL.md` | Setting up Tailwind CSS / NativeWind |
| Jetpack Compose | `expo-ui-jetpack-compose/SKILL.md` | Android native UI modules |
| SwiftUI | `expo-ui-swift-ui/SKILL.md` | iOS native UI modules |
| Data Fetching | `native-data-fetching/SKILL.md` | Data loading, caching, loaders |
| Upgrading | `upgrading-expo/SKILL.md` | Upgrading Expo SDK versions |
| use-dom | `use-dom/SKILL.md` | Using DOM components in React Native |

Each skill directory may also contain a `references/` folder with additional detailed docs. Read those when you need deeper information on a sub-topic.

**Important:** Always try Expo Go first (`npx expo start`) before creating custom native builds.
